# Krishna Jewellers - Mobile App (Flutter)

A cross-platform mobile application for **Krishna Jewellers (Rath, Uttar Pradesh)** replicating the exact UI design, colors, assets, and branding from the website.

---

## 🌟 Highlights & Features

1. **Exact Website Color Scheme & Aesthetics**:
   - Primary Gold: `#D4AF37`
   - Dark Gold: `#A67C00`
   - Light Gold: `#F6E7A8`
   - Header & Dark Luxury Backgrounds: `#0B0B0B`, `#171717`
   - Cream & Card Accents: `#FFF8DF`, `#FFFAF0`
   - Gold Borders: `#EAD9A3`

2. **Full Asset Bundle & Resources**:
   - All original jewelry collection images (Rings, Necklaces, Chains, Kangan, Jhumki, etc.)
   - Showroom promotional banner (`banner.jpg`)
   - Official Store Logo (`logo.png`)
   - Family & Legacy photos (`papa.jpg`, `tauji.jpg`, `rahul.jpg`, `krishna.jpg`)
   - Bundled local `data.json` with fallback support for offline browsing.

3. **Core Functionalities**:
   - **Live Gold Rates Ticker**: Displays live 24K, 22K, and 18K gold rates per 10g synced with the live API with offline fallback.
   - **Category Showcase**: Grid view of all jewelry categories with direct navigation.
   - **Global Search**: Search jewellery items across name, category, and synonyms with instant results.
   - **Jewellery Detail View**: Full screen view with photo carousel, gold weight (grams), hallmark certifications, and trust badges.
   - **Direct WhatsApp & Phone Integration**: Instant 1-click WhatsApp enquiry and phone dialer for Khushipura showroom.
   - **Google Maps Navigation**: 1-click navigation to the store showroom in Rath, UP.
   - **Our Family & Legacy Section**: Replicating the tribute and family heritage cards from the website.

---

## 🚀 How to Run the App

1. Open your terminal and navigate to this folder:
   ```bash
   cd "krishna_jewellers_mobile"
   ```

2. Run on an Android emulator or connected device:
   ```bash
   flutter run
   ```

3. To build an Android APK:
   ```bash
   flutter build apk --release
   ```
